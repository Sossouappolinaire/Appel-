# Appel Prédictions (APK)

Application Android (Java, sans bibliothèque externe) qui fait sonner le téléphone comme un appel entrant quand une
prédiction est lancée dans le canal choisi sur le site (bouton « 📞 Appel APK »).

1. Mets tous ces fichiers à la racine d'un dépôt GitHub (privé de préférence) : l'onglet **Actions** compile l'APK
   (« Compiler l'APK »), à télécharger dans **Artifacts → AppelPredictions-apk**.
2. Dans l'application : adresse Supabase et clé publique (déjà pré-remplies), puis « Enregistrer et démarrer ».
3. Sur le site : « Appel APK » → coche le canal → « Activer » → « Appel de test ».
